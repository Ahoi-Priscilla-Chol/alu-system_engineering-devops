## ssh

remote Ubuntu 20.04 server with a private key, and using
`#!/usr/bin/env bash` in Bash scripts.

| File | Description |
|------|-------------|
| `ssh/0-use_a_private_key` | Connects to the server as `ubuntu` using the private key `~/.ssh/school` |
